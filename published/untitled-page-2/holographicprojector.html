A holographic projector is a device that can create three dimensional images using light. Although this project does not create a hologram it creates what appears to be a 3D object. As it is only refracted light, you cannot touch it nor feel it. This project consists of four adjacent acrylic transparent panes cut and joined in an inverted pyramid style shape with the top cut out. The four panes refract a light from a screen at an ange to then merge and create the appearance of a three dimensional object that can move and shift although it is just four images playing at the same time.
